03 / Real viewport segment demo

真正的雙區段排版範例

畫面區段 1

如果瀏覽器回報水平雙區段，這個區塊會依 viewport-segment-width 0 0 對齊左側畫面。

畫面區段 2

第二區塊會對齊右側畫面；一般手機則採標準單／雙欄響應式版型。

注意：Chrome 138+ 提供 Viewport Segments API；Safari 27.1 的 iPhone Duo 則需在「設定 → App → Safari → 進階 → Feature Flags」開啟 Device Posture API 與 Viewport Segments API，才能測試相關進階特性。這些功能不是所有瀏覽器都有。

此頁面完全在本機運作，不蒐集或上傳偵測數據。官方測試尺寸與 Safari 情境參考：WebKit〈Safari 27.1〉；Samsung Galaxy Z Fold8 模擬值僅作版型示意。
